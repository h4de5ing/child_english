# 芽芽英语：Codex 版本

入口：[index.html](./index.html)。纯 HTML / CSS / JavaScript，无依赖，无需构建。所有儿童交互均为点击，无需识字输入、拖拽或跟读，不申请麦克风权限。

## 预览

直接双击 `index.html` 可体验主要交互。推荐从项目根目录启动静态服务：

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory .
```

打开 <http://127.0.0.1:4173/src_codex/>。手机端页面会自动适配，底部提供探索乐园、我的贴纸、家长入口。

## 整体部署

本版本随项目根目录的首页和 `src_claude` 一起发布到同一个 Cloudflare Worker。部署配置位于仓库根目录，请从根目录运行部署命令。

完整命令和 Cloudflare Git 集成设置见 [项目部署说明](../docs/README.md)。部署后，本版本位于 `/src_codex/`，PWA 作用域也限定在该目录。

## 已实现的交互

1. **14 个主题、152 条词汇**：原有动物、颜色、水果、身体部位、家人、交通工具扩展到每主题 10–18 条；新增数字、形状、天气、食物、衣服、玩具、自然、动作。跨主题词汇可重复，例如水果和颜色中的 orange。
2. **点图听词**：显示英文、中文和图片；可反复播放，已探索状态保存在本机。
3. **学习顺序**：家长可选择顺序或随机学习，默认顺序。词卡每页最多 6 张；顺序模式按词库顺序展示，小游戏每次最多 3 题，完成后保存下一组的位置，覆盖全部词汇后重新开始。随机模式每次进入主题重新排列全部词卡，翻页不重新洗牌；小游戏随机抽 3 个不同单词。选项位置始终打乱，避免记位置作答。
4. **贴纸奖励**：完成一组挑战点亮该主题贴纸，重复挑战不会重复累计；贴纸代表参与，不表示掌握了全主题。答错可重试，不计时、不扣分，保留文字提示。
5. **家长区**：算式入口、探索进度、学习顺序、声音开关、两档难度（2 选 1 / 3 选 1）、试听、安装引导、二次确认重置进度。修改顺序后，关闭家长区会更新词卡；正在进行的挑战按原顺序完成，新挑战使用新设置。
6. **本地保存**：使用 `localStorage`；重新打开可保留进度。损坏、受限的存储不会阻止主要交互。
7. **PWA 基础**：Web App Manifest、192 / 512 PNG 图标、独立窗口模式、Service Worker 资源缓存，以及浏览器安装提示和手动添加引导。

## 原型边界

- 英语朗读通过浏览器 `speechSynthesis` 演示，优先选择设备本地美式英文语音。实际音色、可用性、离线支持依设备而异；部分语音服务可能联网。无语音或关闭声音时，可看文字提示继续小游戏。
- 视觉素材使用系统 Emoji 和 CSS 绘制，外观会随系统变化；家人称谓和图片只是启蒙示意，并非实际家庭成员照片。
- 只保存主题进度和设置，不收集姓名、年龄生日、账号或录音。难度档位仅为本机偏好，无分析 SDK、无业务接口。
- 家长算式用于演示避免儿童误触的交互，不是身份验证或安全边界。
- PWA 安装与 Service Worker 需要支持的浏览器及安全上下文（HTTPS 或当前设备的 localhost）。手机访问电脑的普通局域网 HTTP 地址只能体验页面，不能据此验证 PWA 安装。
- 在支持的环境中首次完整加载、资源缓存成功后，可离线看图和玩游戏。语音可能仍需联网。直接 `file://` 打开不支持 Service Worker。
- 页面支持桌面、平板、手机布局、大点击目标、键盘焦点、弹窗焦点回归、状态播报和减少动态效果偏好。尚未进行真机语音及安装兼容性验收。

## 文件

- `index.html`：页面、样式和交互逻辑。
- `topics.js`：主题词库；原主题 ID 和最初 6 个词的顺序保持不变，兼容旧进度。数字使用数量圆点，形状使用 CSS 图形。
- `manifest.webmanifest`：PWA 配置。
- `sw.js`：仅缓存本目录应用资源；更新资源时同步更新缓存版本号。
- `icons/`：本地应用图标。

首页“开始探索”在顺序模式下继续上次主题，在随机模式下选择不同主题。完成页“继续本主题”进入下一组挑战，“探索下一个小世界”按主题顺序或随机选择；孩子仍可在首页自由选择主题。重置进度会清除挑战位置，但保留家长设置。

验证：从仓库根目录运行 `node tests/codex-learning.cjs`。该检查覆盖学习状态和词库完整性，不替代手机视觉及语音验收。
