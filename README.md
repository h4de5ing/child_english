# 🌱 儿童英语启蒙 · Child English

面向 **3–6 岁儿童**的英语启蒙 Web 项目。通过点图片、听单词和听音选图小游戏，让孩子在熟悉的生活场景中接触英语。

交互以点击为主，无需输入文字或录制跟读。适合家长陪伴孩子一起体验，也可以作为儿童学习产品的交互原型参考。

## 可以做什么

- **看图听词**：点击图片播放英文，结合中文释义认识常见事物。
- **听音小游戏**：听单词、选择图片，答错后可以继续尝试。
- **主题式探索**：从动物、颜色、水果、身体、家人和交通工具等日常场景开始。
- **成长反馈**：用贴纸或星星鼓励参与，学习进度保存在当前浏览器。
- **移动端体验**：适配手机、平板和桌面浏览器，并提供 PWA 支持。

Codex 版本目前包含 **14 个主题、152 条词汇**，还覆盖数字、形状、天气、食物、衣服、玩具、自然和动作。家长可以选择顺序学习或随机学习，以及小游戏的选择难度。词卡每组最多 6 张，方便分次探索。

## 两个版本，一个入口

仓库同时保留两套实现，可以从首页分别进入，体验不同的视觉和交互设计。

| 版本 | 名称 | 代码目录 |
| --- | --- | --- |
| Codex | 芽芽英语 · Little Sprout | [`src_codex/`](./src_codex/) |
| Claude | Hello English | [`src_claude/`](./src_claude/) |

两个版本分别迭代，具体主题、玩法和奖励方式可能不同。统一入口是根目录的 [`index.html`](./index.html)。

## 本地体验

项目使用 HTML、CSS 和 JavaScript。基础预览无需安装前端依赖或执行构建。

安装 Python 后，在仓库根目录执行：

```bash
python -m http.server 4173 --bind 127.0.0.1 --directory .
```

用当前电脑的浏览器打开 **<http://127.0.0.1:4173/>**，选择一个版本开始体验。也可以使用其他静态文件服务器，将仓库根目录作为站点目录。

英语发音使用浏览器或系统的语音服务。部分 Android 设备需要安装可用的 TTS 引擎及英语语音包；音色和离线朗读能力随设备而异。PWA 安装与离线缓存需要支持的浏览器，以及 HTTPS 或当前设备的 localhost 环境。
